# Day 19 | Verilog HDL Implementation of Majority and Minority Detector

## 📖 Introduction

This project demonstrates the implementation of 3-input Majority and Minority Detectors using Verilog HDL. These combinational logic circuits determine whether the majority or minority of the inputs are logic HIGH. The project includes RTL design, functional verification, RTL schematics, and simulation waveforms.

---

## 🎯 Project Objectives

- Understand the working of Majority and Minority Detectors.
- Design combinational logic circuits using Verilog HDL.
- Verify the design using testbenches.
- Generate RTL schematics.
- Analyze simulation waveforms.
